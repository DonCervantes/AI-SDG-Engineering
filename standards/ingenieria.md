# Mínimos de ingeniería (hackathon)

1. Una etapa, un objetivo. No mezcles spec y modelo en el mismo párrafo.
2. Contexto acotado: la IA lee `CONTEXT.md` + el run actual, no todo el historial.
3. Salidas editables: una persona puede rechazar el Markdown.
4. Si una corrección se repite, arregla la plantilla.
5. Evidencia sobre opinión: cada afirmación de precisión tiene una fila en verificación.
6. Ninguna acción sobre un activo físico sin confirmación humana.
7. Waves en orden: no abras wave 2 sin input→salida de wave 1.
8. Código de demo en el repo enlazado; multi-agente paralelo se orquesta allí, no aquí.
