# Cómo copiar plantillas a un run

```text
.ai/runs/AAAA-MM-DD-nombre-equipo/
  CONTEXT.md          (copia desde .ai/CONTEXT.md)
  01-idea.md
  02-architecture.md
  03-build-slice.md
  04-verification.md
  05-pitch.md
  design-brief.md     (si hay UI)
```

Los archivos en blanco están en `/templates`. El ejemplo relleno está en `_ejemplo-mantenimiento-planta`.
