# Cómo usar el ejemplo

Este run (`_ejemplo-mantenimiento-planta`) es un **hackathon ficticio ya rellenado**. No es código de producción.

Cópialo a `.ai/runs/AAAA-MM-DD-tu-equipo/` y sustituye bombas por vuestro activo (línea de envasado, red eléctrica, flota, obra, HVAC).

La lección: **clasificar + RAG filtrado por modelo de máquina** gana a “un agente que lo investiga todo” en 24 horas.
