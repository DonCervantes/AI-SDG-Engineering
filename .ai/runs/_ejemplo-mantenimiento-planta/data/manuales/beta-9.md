# Manual Beta 9 (sintético)

Documento de ejemplo para el run de bombas. No es un manual real de fabricante.

## 1. Identificación

- Modelo: Beta 9
- Activos típicos: B-210 … B-219
- Fluido: agua de utilidades

## 2. Alarmas frecuentes

| Código | Significado |
| --- | --- |
| SEAL-07 | Goteo en sello (sensor Beta) |
| VIB-03 | Vibración elevada |

## 3. Procedimiento — sello (goteo)

### 3.1 Precauciones

- LOTO obligatorio.
- No usar kits ni torques del manual Acme X3.

### 3.2 Goteo / SEAL-07 en Beta 9

1. Confirmar modelo en placa: debe decir Beta 9.
2. Reducir carga; aislar si el goteo aumenta.
3. Revisar asiento Beta-SEAL-B9; sustituir según catálogo Beta.
4. Cualquier valor de apriete: **placa del equipo o supervisor**, nunca un Nm inventado por el modelo.

## 4. Diferencia crítica vs Acme X3

El mismo síntoma “sello” **no** comparte procedimiento ni repuestos con Acme X3. El índice RAG debe filtrar por `modelo_bomba=Beta-9`.
