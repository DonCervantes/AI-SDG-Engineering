# Manual Acme X3 (sintético)

Documento de ejemplo para el run de bombas. No es un manual real de fabricante.

## 1. Identificación

- Modelo: Acme X3
- Activos típicos: B-200 … B-209
- Fluido: agua de utilidades

## 2. Alarmas frecuentes

| Código | Significado |
| --- | --- |
| SEAL-07 | Fuga detectada en sello mecánico |
| BEAR-12 | Ruido / temperatura en rodamiento lado acople |

## 3. Procedimiento — rodamiento (ruido sin fuga)

1. Confirmar que no hay fuga visible.
2. Verificar lubricación y alineación.
3. No aplicar procedimientos de sello.

## 4. Procedimiento — sello mecánico

### 4.1 Precauciones

- LOTO antes de cualquier intervención.
- La IA **no** autoriza trabajo en caliente ni arranque.

### 4.2 Fuga visible / SEAL-07

1. Aislar la bomba B-2xx afectada.
2. Contener el charco; no operar con fuga activa.
3. Inspeccionar caras del sello; reemplazar kit Acme-X3-SEAL si hay surcos.
4. Torque de cierre de prensaestopas: **seguir placa del equipo** (no inventar Nm).
5. Prueba estática y reporte al supervisor.

Procedimientos del modelo Beta 9. Compresores. Recetas de proceso.
